# rahad.dev — Portfolio

Personal portfolio of **Md. Ashikuzzaman Rahad** — Full Stack Developer (MERN & Spring Boot).

Built with **Next.js 14**, **Tailwind CSS**, and **shadcn/ui**-style components. Single-page layout with scroll-reveal animations and dynamic project detail pages.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Sections

- Hero — intro, typewriter, social links
- About — background & interests
- Skills — tech stack categories
- Education — academic timeline
- Projects — 4 full-stack builds with quick links (Code / Live / Details)
- Contact — email, phone, WhatsApp

## Deploy

Push to GitHub and import into [Vercel](https://vercel.com/new).
